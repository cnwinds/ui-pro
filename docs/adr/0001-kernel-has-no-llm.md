# 内核不调用大模型

内核只接受类型化操作，不理解自然语言，也不调用大模型；理解语言、做语义判断的大模型一律在内核之外，通过同一套操作驱动内核。内置助手、外部 Agent、MCP 三种接入方式因此地位相同，得到的结果一致。

内核可以调用感知模型（分割、文字识别、抠图、补全等），但它们通过 Provider 接入，输出随项目锁定，重新构建时不再调用。

## 考虑过的方案

- **内核直接调用大模型，接受自然语言**：上手更省事，但行为取决于模型，无法脱离模型测试和回放，换模型要改内核。

## 后果

- 内核的行为可以脱离任何模型做测试、回放和复现。
- 换大模型不需要改内核；接入方式增减只影响接入层。
- 自然语言到类型化操作的翻译质量，完全由 Agent 和技能说明负责。
