# 图像模型先接阿里云 DashScope，本地感知模型用 ONNX

云端图像模型的第一个 Provider 是阿里云百炼（DashScope）的通义万相图像编辑 `wanx2.1-imageedit`：它的局部重绘（遮罩白区重画、黑区保留）、去文字和超分正好对应补全、文字剥离和提升分辨率三步。密钥只从环境变量 `DASHSCOPE_API_KEY` 读取。本地感知模型通过 onnxruntime 运行，首次用到时从 HuggingFace（连不上时用镜像）下载到用户缓存目录并校验哈希：补全用 LaMa，放大用 Real-ESRGAN 的动漫视频版，角色抠取用 anime-seg。三个模型的许可证都允许商用。

方案 §6.6 原计划在 M0 比较 GPT Image、Seedream 和 Gemini 再定默认。用户目前能提供的是 DashScope 的密钥，所以先接它；Provider 接口用能力声明描述差异，之后增加或更换服务商不影响管线。

## 考虑过的方案

- **千问图像编辑 `qwen-image-2.1` / `3.0`**：画质更新，但接口只收图和文字指令，没有遮罩参数。工具自己做遮罩合成（约束 1）也能用，只是改动范围更难控制；留作状态生成（指令式编辑）的候选。
- **不接云端，纯本地**：没有外发和费用，但角色身后这类大面积补全和 2.5 倍放大达不到商用质量。

## 后果

- 万相接口要求图的宽和高都在 512 到 4096 像素之间。小区域必须带上周围画面裁出至少 512 的块再送，这和约束 3（按原始像素密度送图）一致。
- 接口只能异步调用：提交任务后轮询结果，结果地址 24 小时内有效，取回后立即锁定。
- 没有设置密钥时，构建只用本地模型出初稿，并在报告里说明；设置后用 `ui-pro build --final` 换成终稿。
- 本地模型约 390 MB，按需下载，各项目共用一份。
